# Contributing

Thank you for taking a look at this project.
This repository is a research PoC (not audited). If you want to help, small improvements are welcome: docs fixes, reproducibility, tests, and CI.

## Before you start
- For bugs / questions / feature requests: open a GitHub Issue.
- For security issues: please do not open a public issue. See SECURITY.md.

## Pull requests
- Please link an Issue.
- Keep changes small and focused.
- Explain what changed and why.

## Local checks
Node (CLI demo):
- npm --prefix examples/cli-chat install
- npm --prefix examples/cli-chat run setup
